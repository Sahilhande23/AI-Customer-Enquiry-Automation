# AI Customer Enquiry Automation

An AI-powered customer enquiry automation system built using n8n, AI, Webhooks and Google Sheets, Gmail.

## Workflow

Customer Enquiry
→ Webhook
→ AI Response
→ Google Sheets
→ Gmail
→ Response to Customer

## Features

- Receives customer enquiries through Webhook
- Generates AI-powered responses
- Automatically stores customer details
- Stores customer message and AI reply in Google Sheets
- Returns the AI-generated response
- No manual data entry required
- Automatic Gmail response to customers
- AI-generated email replies
- Gmail API integration

## Technologies Used

- n8n
- AI / LLM
- Webhooks
- Google Sheets
- REST API
- JSON

## Example

Customer Message:

"Hello, I want information about your product."

AI Response:

"I'd be happy to help. Could you please specify which product you're interested in?"
